Análisis de Series Temporales y Pronósticos
===========================================

El curso **Análisis de Series Temporales y Pronósticos** (TSAF, *Time
Series Analysis and Forecasting*) busca ser autocontenido pero se
emplean nociones y métodos de estadística para el análisis de las
series temporales. El lenguaje de programación R es popular en este
área ya que, históricamente, ha sumado numerosas paquetes que ponen en
práctica diferentes modelos y herramientas para el procesamiento de
estos datos. Sin embargo, el crecimiento de Python en el entorno del
aprendizaje automático como la explosión de aplicaciones de
aprendizaje profundo conducen a ofrecer la ejercitación del curso
centrada en este lenguaje. El enfoque para las clases es de *hands-on*
o de tipo de entrenamiento, buscando equilibrar la presentación de los
conceptos teóricos y su puesta en práctica con ejercicios en
computadora. Además, se optó por la biblioteca TensorFlow (TF) para el
estudio con aprendizaje profundo de series temporales considerando de
que se trata de una inciativa abierta, muy bien documentada, y lider
en la industria. Ciertamente, TF se ofrece con *bindings* para
numerosos lenguajes de programación aunque Python es el más
popular. Las funciones de TF, además de estar disponibles a través de
la plataforma Collab, se pueden instalar localmente con relativa
facilidad con el gestor de paquetes de Python o desde un contenedor.

Los contenidos propuestos cubren temas clásicos y modernos que se
organizan en tres partes principales. En primer lugar, abordamos el
análisis de las series temporales en el dominio del tiempo y en el
dominio de la frecuenica. Aquí, introducimos conceptos fundamentales
como la autocorrelación y el espectro de potencias. Luego,
incorporamos las nociones de *windowing* aplicadas a técnicas de
regresión frecuentes. Finalmente, completamos esta primera parte
estudiando modelos estocásticos estacionarios (AR, MA, ARMA) y no
estacionarios (ARIMA, SARIMA). La segunda parte se enfoca en la
aplicación de redes neuronales (NN, *neural networks*) al prónostico
para series temporales. Se presentan los aspectos fundamentales de las
NN para pasar a las unidades LSTM (*Long Short Term Memory*). En este
contexto, se ejemplifica la puesta en práctica de este enfoque con
ayuda de la biblioteca TensorFlow (v2). Finalmente, la tercer parte se
centra en, lo que también se conoce como, técnicas de asimilación de
datos. Particularmente, se introducirá el filtrado de Kalman y sus
variantes.
